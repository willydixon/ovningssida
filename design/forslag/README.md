# Tre förslag på utseende

Förslag på hur den riktiga versionen kan se ut, för William att välja bland (18 november 2026).
Alla tre har samma innehåll och samma funktioner. Bara utseendet skiljer.

- `a.html` Premiär: mörkt och filmiskt, typsnitten Fraunces och Inter
- `b.html` Studio: ljust och kaxigt, typsnitten Bricolage Grotesque och Inter
- `c.html` Neon: energiskt och färgstarkt, typsnittet Sora

Bygg om sidorna med `LUCIDE_DIR=<sökväg till lucide-static/icons> node design/forslag/build.mjs`.

Texterna är utkast. Scenerna Samtalet klockan tre och Sista tåget är påhittade exempel på nya genrer.
Bilderna är egna SVG-illustrationer i `art.mjs`, utan riktiga personer. Ikonerna kommer från Lucide (ISC-licens).
Typsnitten har SIL Open Font License och kommer från Fontsource.
